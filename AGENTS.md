# Musicalia

- Projeto acadêmico: HTML, CSS, JSON e Python via PyScript; sem servidor de aplicação.
- Preservar index.html, src/css/estilo.css, src/python/main.py, src/python/dados.json e src/assets/.
- Dados do catálogo são exemplos. Não incluir segredos ou dados pessoais reais.
- Trabalhar em branches feature/ por tarefa, com commits semânticos; PRs para dev e revisão antes da integração final em main.
- Validar com `python -m unittest discover -s tests -v` e conferir no navegador por HTTP.
- Commit, push e merge não publicam o site. Publicação é manual, após homologação.
- Instruções de execução, contrato e publicação estão em README.md e docs/.
